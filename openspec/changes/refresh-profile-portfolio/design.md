## Context

这是静态 GitHub profile 仓库。用户已选择 AI × Web3 作品集方向并要求保留 Captain 风格。GitHub 连接器已核实五个公开仓库的 README；captain-dock 内容 API 明确返回仓库为空。

## Goals / Non-Goals

**Goals:** 保留品牌横幅与配色，展示具体成果、真实仓库和项目状态，以中文提供项目介绍。

**Non-Goals:** 本次不新建网站，不调整 GitHub 置顶仓库或账号设置，不更改联系方式、既有获奖信息与用户本地配置。

## Decisions

1. 采用内容与卡片刷新。备选为大幅视觉重设计或截图画廊；当前视觉已完整，刷新内容可以集中表达近期成果并降低资产维护成本。
2. 第一排展示 ArcPredict、GiwaIntent、PredictArena；第二排展示 web_demo、ai-config-templates。个人网站移入品牌介绍及联系区，旧 captain-dock 卡片作为历史资产保留但不引用。
3. 卡片使用中文说明和已有 SVG 图形结构；保留品牌及仓库英文名称。统一标题、描述的字体回退以支持中文。
4. README 以项目表格说明功能与阶段，卡片提供仓库入口。保留旧大模型模板锚点以兼容已有链接，同时新增真实仓库链接。
5. 将旧测试中的过期英文营销文案替换为成果与状态断言，并扩展 SVG 检查到全部资产，覆盖已停用卡片。

## Risks / Trade-offs

- 项目持续变化 → 文案只陈述当前公开 README 可证实的能力，避免写成生产产品。
- SVG 中文字体取决于客户端 → 使用系统字体、苹方、微软雅黑与通用 sans-serif 回退，视觉检查文字布局。
- 网站可用性尚未核实 → 保留用户既有网址，不新增上线声明。
- 已有获奖、地点信息来自原主页 → 保留原意，不扩写获奖名次或日期。

## Migration Plan

先写失败测试，再修改 README 与 SVG，运行完整 unittest、OpenSpec 校验及 diff 空白检查。先交付本地预览，发布独立进行。
